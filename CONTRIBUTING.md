# Contributing

Contributions that improve tracker detection, rule quality, documentation, tests or schema compatibility are welcome.

Before proposing a change:

- do not commit credentials, production exports, personal data or private browsing data;
- document the evidence for new or changed tracker rules;
- keep rules deterministic and explainable;
- run the repository validation scripts when applicable;
- keep changes focused and describe compatibility impacts clearly.

Security issues should be reported privately as described in `SECURITY.md`, not through a public issue.

By contributing, you agree that your contribution is provided under the repository's GPL-2.0-or-later license.
