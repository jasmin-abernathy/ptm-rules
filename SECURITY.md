# Security policy

## Supported code

The current `main` branch is the only branch considered for security fixes while the project is pre-1.0.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue.

Send a private report to `contact@lepotager.org` with the subject `Security — PTM Rules`. Include the affected version or commit, reproduction steps, expected impact and any suggested mitigation.

Do not include real credentials, personal data or production exports in reports. Use minimal synthetic examples whenever possible.

Reports will be assessed before any public disclosure or release note is published.
